Engineering Standards Applied Across Projects

Baseline practice carried through every Kirby CMS, TYPO3 and WordPress build delivered for berbach GmbH clients.

  • Separate development and production environments for every project (staging on All-Inkl for Kirby builds; dedicated staging for WordPress/TYPO3)
  • In-house plugin suite reused across all Kirby CMS projects: XML sitemap generator, SEO meta tooling, GDPR-compliant consent-banner, client-side email/phone obfuscation ("crypto"), tag management — each with its own Panel-side configuration UI built in Vue.js (Kirby's admin Panel is a Vue application)
  • Google Maps API, Google Analytics, Matomo Analytics and Google Search Console wired in as standard on every Kirby project
  • Contact forms with transactional mail delivery on every site
  • TYPO3 builds implemented on Foundation (ZURB) or UIkit; Kirby builds on hand-written vanilla SCSS and modular vanilla JavaScript (no framework dependency)
  • MySQL as the standard database for TYPO3, WordPress, Shopware and Symfony projects; Kirby CMS projects use its flat-file, database-free folder structure instead
  • Shared accessible lightbox component (keyboard navigation, focus trapping, ARIA labeling) used as a standard image/gallery viewer across every website, regardless of CMS
  • Browser, performance, Google, SEO and accessibility optimization prior to every launch
